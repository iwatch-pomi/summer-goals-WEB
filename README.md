# 夏限定・ガチ活（仮） — 事前登録LP

大学生向け「目標達成デポジットマッチングアプリ」の事前登録・決済促進用ランディングページです。

3,500円（システム料500円＋デポジット3,000円）を前払いし、30日間サボらず証拠写真を報告して完走すれば3,000円が全額返金される、というサービスを訴求します。

## 構成

- `index.html` — LP本体（静的1ファイル）
- `.nojekyll` — GitHub Pages の Jekyll 処理を無効化
- `README.md` — 本ファイル

ビルド不要。Tailwind CSS は CDN から読み込むため、`index.html` をブラウザで開くだけで表示できます。

## ローカルで確認する

```bash
# このディレクトリで簡易サーバーを起動
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

または `index.html` をダブルクリックして直接開いてもOKです。

## GitHub Pages で公開する手順

このリポジトリには既にファイルがプッシュされています。公開には管理者による以下の手動操作が必要です。

1. GitHub のリポジトリページを開く
2. **Settings → Pages** へ移動
3. **Build and deployment → Source** で **「Deploy from a branch」** を選択
4. **Branch** で公開したいブランチ（例：`claude/summer-goal-app-lp-2maehy` または `main`）と **`/ (root)`** を選択して **Save**
5. 数分後、`https://<ユーザー名>.github.io/summer-goals-web/` で公開されます

> 公開ブランチを `main` にしたい場合は、本ブランチを `main` にマージしてから上記 Source を `main` に設定してください。
